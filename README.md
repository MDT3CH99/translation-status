# Thai-Lang — ม็อดแปลไทย

เว็บไซต์รวมโปรเจกต์ม็อดแปลภาษาไทยแบบฟรี พร้อมเครื่องมือเช็คสถานะแปล

🔗 **เว็บไซต์:** https://mdt3ch99.github.io/translation-status/
💬 **ดิสคอร์ด:** https://discord.gg/5U4xm3hmmk

## มีอะไรในเว็บนี้

- **โปรเจกต์ทั้งหมด** — รวมม็อดแปลไทยที่ทำอยู่/ปล่อยแล้ว พร้อมลิงก์ดาวน์โหลด
- **เครื่องมือเช็คสถานะแปล** — อัปโหลดไฟล์ .txt/.csv เพื่อเช็คว่าแปลไปกี่ % แยกตามหมวด (บทพูด/UI/อื่นๆ) ทำงานในเครื่องผู้ใช้เอง ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์

## เพิ่มเกมใหม่

แก้ไฟล์ `index.html` หาคอมเมนต์ `// เพิ่มเกมใหม่:` ในส่วน `<script>` ท้ายไฟล์ แล้วก็อปอ็อบเจกต์เกมหนึ่งอันไปแก้ค่า
